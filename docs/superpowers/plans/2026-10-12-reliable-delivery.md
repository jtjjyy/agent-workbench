# 可靠任务与桌面交付实施计划

> 执行方式：在现有工作树按模块分配独立子 Agent，主 Agent 串行集成公共文件。用户已确认推荐方案，无需再次确认。

**目标：** 为现有中文开发者工作台增加任务续接、受审查的多文件交付闭环和稳定桌面交付基础。

**架构：** 保持 Pi 唯一运行内核。新增任务存储、变更集服务、桌面交付服务，通过现有协调器、受信任 IPC 与 React 客户端集成。

**技术栈：** TypeScript、Electron、React、TypeBox、Pi、Node 文件与子进程 API。

## 全局约束

- 不运行测试、构建、类型检查、打包、真实模型请求。
- 中文用户界面；不使用已泄露密钥；不提交代码或推送，除非用户另行要求。
- 不覆盖用户改动；不自动重放副作用调用；不宣传审批为沙箱。
- 公共入口文件仅由主 Agent 修改，子 Agent 只能修改所分配的新模块。
