# 第九阶段 Skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为本地开发者 Agent 增加声明式 Skills 的管理、匹配和运行时注入能力。

**Architecture:** Skills 由主进程加载和校验，使用内置定义加用户数据目录中的 Markdown 定义；RunCoordinator 只把已启用且匹配当前任务的 Skill 指令传给 Pi 运行时。Skill 永远不能新增工具、权限或绕过审批。

**Tech Stack:** Electron 主进程、TypeScript、React、现有 Pi Agent Core、现有 IPC Bridge 和 JSON 本地存储。

## Global Constraints

- 所有新增客户端文案使用简体中文。
- 不新增可执行插件、不新增命令执行权限、不新增 MCP 权限。
- 不维护第二套 Agent 内核，继续复用现有 Pi Agent Core。
- 当前不运行测试、类型检查、lint、构建、打包、浏览器自动化或真实模型请求。
- 不写入或复述聊天中暴露的密钥。
