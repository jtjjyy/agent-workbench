# 客户端中文化实施计划

## 目标与边界

按用户要求直接进行现有客户端的简体中文翻译，不改动既有功能和协议。
应用标题、设置、状态、错误、事件轨迹、无障碍标签、菜单和新生成的本地模拟回复使用中文。
模型默认以中文回答，保留技术标识和必要原文。历史对话、密钥、工作区数据保持原样。
内部 package 名称不更改，避免影响应用数据路径、安装器标识和已有会话。

## 任务

- [x] 读取当前客户端、设置和运行时源码，保留尚未提交的模型接入改动。
- [x] 创建共享中文事件和错误文案，写入根目录 AGENTS.md 语言约定。
- [x] 界面子 Agent：翻译标题、设置、状态、无障碍标签、事件轨迹；保留业务逻辑。
- [x] 主 Agent：翻译系统对话框、运行时安全错误、模拟回复和默认模型提示；建立中文菜单。
- [x] 测试夹具子 Agent：只同步受影响的定位器和文案断言，不运行测试。
- [x] 在中文交付说明中记录历史内容及第三方文本边界，README 改为中文。
- [x] 正常关闭旧窗口，重新启动后已出现“开发者智能体工作台”窗口，并切到前台。未运行额外测试或触发模型请求。

## 验收与证据

用户可看到中文窗口、会话、轨迹和模型设置，事件协议标识不变。
本轮按既有要求不执行单元测试、端到端、截图或模型验证；正常启动编译不等于全部功能验证。
新增 UI 文案、错误分支和学习文档默认中文，由项目约定约束后续工作。

正常启动编译未出现类型错误；主进程仍有 Pi 依赖动态导入表达式的构建警告。
该警告与上一版启动相同，本轮不扩展修改 SDK 或进行打包验证，不宣称所有运行时路径已验证。
