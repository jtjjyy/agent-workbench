# 第五阶段：记忆、项目知识库、增量索引

## 已实现

- 本地 JSON 记忆存储：用户记忆可保存和删除，项目记忆绑定项目标识。
- 项目文本索引：复用现有工作区安全扫描，限制最多 200 个文件，每文件最多 64 个片段。
- 增量复用：文件路径、大小、mtime、ctime 和 SHA-256 均未变化时复用原片段。
- 证据检索：返回相对路径、起止行号、SHA-256 和有限文本片段。
- Agent 工具：`search_knowledge`、`read_project_knowledge`。
- 客户端：索引状态、同步、关键词检索、用户记忆保存与删除。

## 明确边界

本阶段是本地关键词检索，不是向量 RAG：没有 Embedding、向量数据库、语义重排或自动长期记忆写入。索引和记忆是本地明文数据，不是安全存储。工作区策略不是操作系统沙箱；外发授权仍是模型读取项目内容的必要条件。
