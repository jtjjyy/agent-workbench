## 原理学习

- 工具循环不等于多 Agent 协作；开发时多个子 Agent 帮写代码，也不是产品已经支持多 Agent。
- 当前字面搜索不等于向量检索、RAG 完整流水线或增量索引；检索无结果也不等于仓库没有相关内容。
- SHA-256 标识读取时字节快照，不证明模型结论正确，也不解决提示注入。
- 检查路径、弹窗确认、渲染进程 sandbox 和 OS 主进程文件系统隔离是不同机制。当前没有宣称实现 OS 工具沙箱。
- 当前限制上下文字符数并筛选历史，没有实现语义压缩、可管理记忆或完整检查点恢复。
