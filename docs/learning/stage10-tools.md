# 工具能力：命令、联网与浏览器

## 三个独立子阶段

1. `run_powershell`：在用户选定且同意数据外发的工作区根目录执行非交互 PowerShell。每次调用绑定完整命令、工作目录和参数，支持审批、超时、取消、输出上限和退出码。
2. `web_search`、`web_fetch`：搜索公开网页并读取有限正文。它们只需要 DeepSeek 的数据外发授权，不需要用户选择代码工作区；来源包含 URL 和抓取时间，网页内容是不可信数据，不自动写入记忆或项目索引。未配置专用搜索服务时使用公开 HTML 搜索；不能返回结果时不伪造结果。
3. `browser_open`、`browser_read`、`browser_screenshot`、`browser_click`、`browser_type`：复用 Electron 可见的“Agent 浏览器”窗口会话。只允许 HTTP/HTTPS，固定读取和交互脚本，不允许模型执行任意 JavaScript；点击和输入逐次审批。

## 安全边界

审批是一次具体操作的授权，不是永久授权，也不是操作系统沙箱。PowerShell 仍可能访问同权限资源，浏览器会话也不等同于隔离浏览器。取消、超时、进程关闭或日志写入失败时，结果可能未知，不自动重放带副作用的调用，也不承诺自动回滚。

工作区、网页、命令输出和浏览器页面均视为不可信数据。数据外发仍由模型设置和工作区同意控制；API 密钥继续使用 Electron `safeStorage`，不写入工具参数、日志或事件正文。
